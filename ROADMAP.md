# Roadmap

## v0.2 — semantic foundation
- state envelope
- lineage and ACK lifecycle
- task graph
- capability registry
- memory classes
- controlled learning ledger
- conformance benchmark

## v0.3 — adapters and negotiation
- provider adapter interface
- multi-agent conflict negotiation
- signed state digests
- richer evidence/provenance
- capability discovery exchange

## v0.4 — distributed runtime
- local/cloud node handshake
- state persistence backend
- event transport adapters
- policy profiles
- replay and deterministic audit tooling

## v1.0 criteria
- stable normative schema
- at least three independent implementations or adapters
- published interoperability benchmark results
- backwards-compatibility policy
- security review of execution boundary
