## Protocol evolution
- Changes to normative semantics require a proposal and tests.
- Breaking changes require a new protocol version.
- Historical meanings must not be silently redefined.
- Reference SDK behavior does not automatically become normative protocol behavior.

## Maintainer authority
The creator/maintainer controls release acceptance for the canonical repository while the project remains in alpha.
