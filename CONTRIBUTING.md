# Contributing

Contributions are welcome.

1. Open an issue or proposal for semantic changes.
2. Keep protocol changes vendor-neutral.
3. Add or update conformance tests.
4. Do not require hidden chain-of-thought disclosure.
5. Keep execution permissions separate from model decisions.
6. Run `python -m unittest discover -s tests -v` before submitting.

By contributing, you agree that your contribution is licensed under Apache-2.0.
