# Interoperability Testing

SMTYX testing is intentionally provider-neutral.

A model is tested on whether it can:
1. reconstruct required state fields,
2. preserve uncertainty,
3. distinguish verification from confidence,
4. maintain lineage,
5. detect conflict,
6. avoid treating tool requests as authorization,
7. represent task dependencies,
8. distinguish memory types,
9. respect controlled learning stages.

Use `prompts/AI_CONFORMANCE_PROMPT.md` and `benchmarks/conformance_cases.jsonl`.
