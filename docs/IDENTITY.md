## Concept

SMTYX is a coined technology name inspired by three related layers:

- **syntax** — how a message is structured,
- **semantics** — what the message means,
- **semiotics** — how signs and representations carry and produce meaning.

SMTYX is defined as a **Semantic Language and Protocol for Intelligent Systems**.
It is designed to remain independent of any single model vendor, transport, agent
framework, or orchestrator.

Nara may use SMTYX as a reference orchestrator, but Nara is not part of the core
protocol and is not required for conformance.

## Experimental developer identifiers

The reference project uses `SMTYX` as the protocol identifier and `smtyx` as the
software/package namespace. The `.smx` file suffix and `application/smtyx+json`
media type are **experimental project conventions** in v0.2 and are not claimed to
be registered standards or IANA media types.
